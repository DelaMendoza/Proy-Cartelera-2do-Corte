# Endpoints

## VISTA

- GET / - Devuelve "Bienvenido {nombre}".
- GET /peliculas - Muestra la lista de películas.
- GET /peliculas/{id} - Muestra la ficha de una película.
- GET /peliculas/nueva - Muestra el formulario para crear una película.
- GET /peliculas/{id}/editar - Muestra el formulario para editar una película.
- POST /peliculas - Crea una película.
- POST /peliculas/{id} - Edita una película.
- POST /peliculas/{id}/eliminar - Elimina una película.

## API

- GET /api/peliculas - Lista las películas.
- GET /api/peliculas/{id} - Busca una película por id.
- POST /api/peliculas - Crea una película.
- PUT /api/peliculas/{id} - Edita una película.
- DELETE /api/peliculas/{id} - Borra una película.
